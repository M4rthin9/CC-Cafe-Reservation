1. หน้าเข้าสู่ระบบ (Login)

📸 ภาพ: หน้า Login แสดงฟอร์มกรอก Username และ Password พร้อมปุ่ม "เข้าสู่ระบบ"
  1. เปิด URL: https://[domain]/admin.html
  2. กรอก ชื่อผู้ใช้ (Username) และ รหัสผ่าน (Password)
  3. กดปุ่ม "เข้าสู่ระบบ"
  4. หากข้อมูลถูกต้องจะเข้าสู่หน้า Dashboard ทันที
  5. หากผิดพลาดจะแสดงข้อความ error สีแดง
💡 หมายเหตุ: ระบบจะซ่อนเมนูตามสิทธิ์ของผู้ใช้โดยอัตโนมัติ — แต่ละบทบาทจะเห็นเฉพาะฟังก์ชันที่เกี่ยวข้อง

2. ภาพรวมแดชบอร์ด (Dashboard)

📸 ภาพ: Dashboard ทั้งหน้า แสดงสถิติ 4 ตัวด้านบน กราฟแนวโน้ม สถานะ Pipeline สรุปการเงิน

สถิติหลัก (4 ตัว)

รายการคำอธิบาย
📋 การจองทั้งหมดจำนวนการจองทั้งหมดในระบบ
⏳ รอตรวจสอบวินัยจำนวนที่รอ Vinai ตรวจสอบ
✅ อนุมัติ / รอชำระจำนวนที่ผ่านการตรวจสอบแล้ว
❌ ไม่อนุมัติจำนวนที่ถูกปฏิเสธ

กราฟแนวโน้ม (Trend Chart)

📸 ภาพ: กราฟแท่งแนวโน้ม 14 วัน กราฟแท่งสีน้ำเงินพร้อมยอดทอง แสดงจำนวนการจองในแต่ละวัน ย้อนหลัง 14 วัน — ชี้เมาส์เพื่อดูรายละเอาย

แสดงจำนวนการจองในแต่ละวัน ย้อนหลัง 14 วัน สามารถชี้เมาส์เพื่อดูจำนวนในแต่ละวันได้

สถานะ Pipeline

📸 ภาพ: แถบ Pipeline แถบสีต่าง ๆ แสดงสัดส่วนของแต่ละสถานะ: ฟ้า (วินัย), ส้ม (ผู้เข้าร่วม), เหลือง (ชำระเงิน), เขียว (ชำระแล้ว), ม่วง (เสร็จสิ้น), แดง (ปฏิเสธ), เทา (ยกเลิก)

แสดงสัดส่วนของแต่ละสถานะเป็นเปอร์เซ็นต์ของทั้งหมด

สรุปการเงิน (Finance Overview)

📸 ภาพ: แผงสรุปการเงิน + กราฟเส้น แสดง KPI การเงิน 3 ตัว (ยอดจอง, ชำระแล้ว, ยังไม่ชำระ) พร้อมกราฟเส้นแนวโน้ม 14 วัน

3. จัดการการจอง (Reservations)

📸 ภาพ: ตารางรายการจองทั้งหมด แสดง Search bar, ตัวกรอง, ตารางพร้อม Checkbox, สถานะ badge, ปุ่มดำเนินการ

การค้นหาและกรอง

  • 🔍 ช่องค้นหา — พิมพ์ชื่อผู้จอง / Ref No. / ชื่อผู้ต้องขัง เพื่อค้นหา
  • 📌 กรองสถานะ — เลือกสถานะที่ต้องการดู
  • 📅 กรองวันที่ — เลือกวันที่ต้องการดู
  • 🏢 กรองแดน — เลือกแดนที่ต้องการดู

การดำเนินการกับรายการจอง

📸 ภาพ: แถบปุ่มดำเนินการในแต่ละแถว แสดงปุ่ม 🧾 สลิป, 📋 รายละเอียด, ✏️ แก้ไข, ✓ อนุมัติ, 💳 ยืนยันชำระ, ✗ ปฏิเสธ, 🚫 ยกเลิก
ปุ่มการทำงานบทบาทที่ใช้ได้
🧾 สลิปดูรูปสลิปโอนเงินทุกบทบาท
📋 รายละเอียดดูข้อมูลทั้งหมดของรายการนี้ทุกบทบาท
✏️ แก้ไขแก้ไขข้อมูลการจองSuperadmin, Admin
✓ อนุมัติวินัยอนุมัติผ่าน VinaiSuperadmin, Admin, Vinai

✗ ปฏิเสธปฏิเสธการจองSuperadmin, Admin, Vinai, Tadtel
🚫 ยกเลิกยกเลิกการจองSuperadmin, Admin

การทำ Bulk Actions (เลือกทีละหลายรายการ)

  • เลือก Checkbox ด้านหน้าแถวที่ต้องการ
  • แถบ Bulk Action จะแสดงด้านล่างตาราง
  • สามารถเปลี่ยนสถานะทีละหลายรายการได้พร้อมกัน

Pagination (แบ่งหน้า)

  • เลือกจำนวนรายการต่อหน้า: 5 / 10 / 20 / 50
  • ปุ่ม ← → สำหรับเปลี่ยนหน้า
  • แสดงจำนวนรายการทั้งหมด

4. สร้างการจองใหม่ (New Booking)

📸 ภาพ: Modal สร้างการจองใหม่ (เต็ม) แสดงฟอร์มทั้งหมด: ข้อมูลผู้จอง, ผู้เข้าร่วมเพิ่มเติม, ค้นหาผู้ต้องขัง, เลือกวันที่
🔒 เฉพาะ: Superadmin และ Admin เท่านั้นที่สร้างการจองใหม่ได้

ขั้นตอนการสร้างการจอง

4.1 กรอกข้อมูลผู้จอง

  • ชื่อ-นามสกุล (required)
  • เลขประจำตัว — บัตร ปชช. รูปแบบ X-XXXX-XXXXX-XX-X หรือ Passport No.
  • เบอร์โทรศัพท์ — 10 หลัก
  • ความสัมพันธ์ — เลือกจาก dropdown
  • ศาสนา — พุทธ / อิสลาม / คริสต์ / อื่น ๆ
  • การแพ้อาหาร — กรอกรายละเอียด หรือ "ไม่มี"

4.2 ผู้เข้าร่วมเพิ่มเติม

  • เลือกจำนวนผู้เข้าร่วม (รวมผู้จอง) จาก dropdown
  • กรอกข้อมูลของแต่ละคน: ชื่อ, เลขประจำตัว, ศาสนา, แพ้อาหาร, ความสัมพันธ์, อายุ
  • หากเลือกความสัมพันธ์เป็น "บุตร / ธิดา" ต้องกรอกอายุ

4.3 ค้นหาผู้ต้องขัง

📸 ภาพ: ช่องค้นหาผู้ต้องขังพร้อม dropdown suggestions แสดงช่องค้นหา, Dropdown รายการที่ตรงกัน, กรอบสีเขียวแสดงข้อมูลที่เลือกแล้ว
  1. พิมพ์เลขผู้ต้องขัง หรือชื่อ-นามสกุล ในช่องค้นหา
  2. ระบบจะแสดงรายการที่ตรงกัน (สูงสุด 8 รายการ)
  3. คลิกเลือกผู้ต้องขังจาก dropdown
  4. ข้อมูลจะแสดงในกรอบสีเขียวยืนยัน — ชื่อถูกปิดบัง (mask) เพื่อความเป็นส่วนตัว
  5. คลิกพื้นที่ว่างเพื่อปิด dropdown

หากระบบไม่พบผู้ต้องขังที่ต้องการ แสดงว่าข้อมูลในฐานข้อมูลยังไม่มี — สามารถป้อนข้อมูลผ่านหน้า "จัดการผู้ต้องขัง" ก่อน

⚠️ ความเป็นส่วนตัว: ชื่อผู้ต้องขังจะถูกปิดบัง (แสดงเฉพาะชื่อต้น + 4 ตัวแรกของนามสกุล) เพื่อป้องกันข้อมูลส่วนบุคคล

4.4 เลือกวันที่

  • เลือกวันที่ต้องการเข้าร่วมกิจกรรมจาก input date
  • ค่าบริการรวมจะคำนวณอัตโนมัติ

4.5 บันทึก

  • กดปุ่ม 💾 บันทึกการจอง
  • ระบบจะบันทึกไปยัง Google Sheet ทันที
  • สถานะเริ่มต้น: รอตรวจสอบวินัย
  • เลขอ้างอิง (Ref) จะถูกสร้างอัตโนมัติ

5. แก้ไขการจอง (Edit Booking)

📸 ภาพ: Modal แก้ไขการจอง แสดงฟอร์มแก้ไขข้อมูลผู้จอง ผู้เข้าร่วม ผู้ต้องขัง และวันที่
  1. คลิกปุ่ม ✏️ แก้ไข ในแถวที่ต้องการ
  2. Modal จะแสดงพร้อมข้อมูลเดิม
  3. สามารถแก้ไข:
    • ข้อมูลผู้จอง (ชื่อ, ID, เบอร์โทร, ความสัมพันธ์, ศาสนา, แพ้อาหาร)
    • ผู้เข้าร่วมเพิ่มเติม (เพิ่ม/ลบ/แก้ไข)
    • ผู้ต้องขัง (ชื่อ, ID, แดน)
    • วันที่เข้าร่วม
  4. กด 💾 บันทึก เพื่อบันทึก
  5. กด ✕ ยกเลิก เพื่อยกเลิก
⚠️ ข้อควรระวัง: การแก้ไขข้อมูลผู้ต้องขังจะไม่ตรวจสอบกับฐานข้อมูลผู้ต้องขังอีกครั้ง — ตรวจสอบให้แน่ใจก่อนบันทึก

6. จัดการผู้ต้องขัง (Prisoners)

📸 ภาพ: หน้าจัดการผู้ต้องขัง แสดงฟอร์มอัปโหลด CSV, ปุ่มแสดงตัวอย่าง, ปุ่ม Sync Wings

นำเข้าข้อมูลจากไฟล์ CSV

  1. เลือกว่าไฟล์ CSV ที่มีรูปแบบ: prisonerId, prisonerName, wing
  2. กดปุ่ม 👁️ แสดงตัวอย่าง เพื่อดูตัวอย่างข้อมูล
  3. ตรวจสอบความถูกต้องของตัวอย่าง
  4. กดปุ่ม 💾 ยืนยันนำเข้า เพื่อบันทึก

ระบบจะ อัปเดตอัตโนมัติ (Upsert) ถ้า prisonerId ซ้ำ — ไม่ต้องกังวลเรื่องข้อมูลซ้ำ

💡 แนะนำ: นำเข้าข้อมูลผู้ต้องขังก่อนเปิดใช้ระบบครั้งแรก เพื่อให้ช่องค้นหาผู้ต้องขังทำงานได้อย่างสมบูรณ์

Sync Wings

ปุ่ม 🔄 Sync Wings — ใช้สำหรับอัปเดตแดน (wing) ในรายการจองทั้งหมด ตามข้อมูลผู้ต้องขังล่าสุด

  • มีประโยชน์เมื่อผู้ต้องขังถูกย้ายแดน
  • ระบบจะอัปเดตแดนในทุกรายการจองที่อ้างถึงผู้ต้องขังนั้น

7. รายงาน (Reports)

📸 ภาพ: หน้ารายงาน แสดงตารางข้อมูลการจองพร้อมช่องค้นหาและปุ่มส่งออก

ฟังก์ชันที่มี

  • ค้นหา — พิมพ์ชื่อ / Ref / ผู้ต้องขัง
  • ส่งออก CSV — ดาวน์โหลดข้อมูลเป็นไฟล์ CSV
  • ส่งออก CSV มีเบอร์ — ส่งออกรวมเบอร์โทรศัพท์
  • ส่งออก CSV ตามช่วงวันที่ — เลือกวันที่เริ่มต้น-สิ้นสุด
  • 🖨️ พิมพ์ — พิมพ์รายงาน

8. รายงานทางการ (Formal Reports)

📸 ภาพ: หน้ารายงานทางการ แสดงรายงานรูปแบบทางการพร้อมตัวเลือกพิมพ์และส่งออก
  • รายงานรูปแบบทางการพร้อมหัวเอกสารและตราประทับ
  • เลือกแดนเพื่อกรอง
  • สามารถพิมพ์และส่งออกได้

9. บันทึกการทำงาน (Event Log)

📸 ภาพ: หน้า Event Log แสดงตารางประวัติการดำเนินการ: เวลา, ผู้ใช้, บทบาท, การกระทำ, รายละเอียด
คอลัมน์คำอธิบาย
🕐 เวลาวันที่และเวลาที่ดำเนินการ
👤 ผู้ใช้Username ที่ดำเนินการ (พร้อมบทบาท)
📝 การกระทำประเภทของการกระทำ เช่น update_status, confirm_payment
📋 รายละเอียดรายละเอียดเพิ่มเติม เช่น Ref No., ข้อมูลที่เปลี่ยน
💡 ใช้สำหรับ: ตรวจสอบ Audit Trail — ดูว่าใครทำอะไร เมื่อไหร่ ในระบบ

แสดงสูงสุด 100 รายการล่าสุด บันทึกอยู่ใน LocalStorage ของเบราว์เซอร์

10. จัดการผู้ใช้ (Users)

📸 ภาพ: หน้าจัดการผู้ใช้ แสดงตารางผู้ใช้ พร้อมปุ่มเพิ่ม/แก้ไข/ลบ
🔒 เฉพาะ: Superadmin เท่านั้นที่เข้าถึงหน้านี้ได้
  • เพิ่มผู้ใช้ใหม่ — กรอก Username, Password, เลือกบทบาท
  • แก้ไขผู้ใช้ — เปลี่ยนชื่อผู้ใช้, รหัสผ่าน, บทบาท
  • ลบผู้ใช้ — ลบผู้ใช้ออกจากระบบ

12. จัดการตั้งค่า (Settings)

📸 ภาพ: หน้าตั้งค่า แสดงฟอร์มกำหนดค่าต่าง ๆ ของระบบ
🔒 เฉพาะ: Superadmin เท่านั้นที่เข้าถึงได้
  • กำหนดค่า URL ของ Google Apps Script
  • ปรับปรุง ค่าบริการ ต่อคน
  • กำหนด จำนวนโควต้า สูงสุดต่อวัน
  • ตั้งค่า การแจ้งเตือน (Notification)

13. เคล็ดลับการใช้งาน

การรีเฟรชข้อมูล

  • ข้อมูลจะอัปเดตอัตโนมัติทุก 30 วินาที
  • หรือกดปุ่มรีเฟรช (🔄) ที่มุมบนขวา
  • บนมือถือสามารถใช้ Pull-to-Refresh (ดึงลง) เพื่อรีเฟรช

การแจ้งเตือน

  • 🔔 กระดิ่งแจ้งเตือนจะแสดงเมื่อมีรายการจองใหม่ในสถานะ "รอตรวจสอบ"
  • คลิกที่กระดิ่งเพื่อดูรายละเอียด
  • คลิกที่รายการในแผงแจ้งเตือนเพื่อไปที่รายการนั้น

ปุ่มคู่มือ

  • คลิก 📖 คู่มือ ที่มุมบนขวาของหน้า Admin เพื่อเปิดคู่มือนี้ในแท็บใหม่
  • ใช้ปุ่ม 🖨️ พิมพ์ ที่มุมบนขวาของคู่มือเพื่อพิมพ์

การจัดการหน้าจอบนมือถือ

  • ระบบปรับขนาดอัตโนมัติตามหน้าจอ (Responsive)
  • บนมือถือเมนูด้านข้างจะถูกซ่อนและแสดงปุ่ม ☰ เพื่อเปิด
  • แถบนำทางด้านล่าง (Bottom Nav) แสดงบนมือถือเพื่อการเข้าถึงที่รวดเร็ว

14. การแก้ไขปัญหาเบื้องต้น

ปัญหาสาเหตุวิธีแก้
🔴 เข้าสู่ระบบไม่ได้ ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง ตรวจสอบข้อมูลประจำตัวและลองใหม่ — ติดต่อ Superadmin ถ้าลืมรหัสผ่าน
🟡 โหลดข้อมูลไม่สำเร็จ ไม่สามารถเชื่อมต่อ Google Sheet หรืออินเทอร์เน็ต ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต รอสักครู่แล้วกดรีเฟรช
🟡 ข้อมูลไม่แสดง ตัวกรอง (Filter) อาจซ่อนข้อมูล ล้างตัวกรองทั้งหมด: สถานะ = "ทุกสถานะ", วันที่ = "ทุกวัน", แดน = "ทุกแดน"
🔴 บันทึกข้อมูลไม่สำเร็จ ลิงก์ Google Apps Script ขาด หรือมีปัญหาเซิร์ฟเวอร์ ตรวจสอบ URL Apps Script ในหน้าตั้งค่า ติดต่อผู้ดูแลระบบ
🟡 ค้นหาผู้ต้องขังไม่เจอ ข้อมูลผู้ต้องขังยังไม่ได้นำเข้า หรือยังไม่โหลด ไปที่หน้า "ผู้ต้องขัง" → นำเข้า CSV → กด Sync Wings
🟡 Modal ไม่แสดง หรือแสดงผิดปกติ อาจมี CSS ขัดกัน หรือ Cache เดิม กด Ctrl+F5 (Hard Refresh) เพื่อล้าง Cache
🚨 หากปัญหายังไม่หาย: กรุณาติดต่อผู้ดูแลระบบ (Superadmin) หรือแจ้งที่ทีมพัฒนาผ่านช่องทางที่กำหนด
