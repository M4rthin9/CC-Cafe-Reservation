ขั้นตอนการสร้างการจอง

4.1 กรอกข้อมูลผู้จอง

  • ชื่อ-นามสกุล (required)
  • เลขประจำตัว — บัตร ปชช. รูปแบบ X-XXXX-XXXXX-XX-X หรือ Passport No.
  • เบอร์โทรศัพท์ — 10 หลัก
  • ความสัมพันธ์ — เลือกจาก dropdown (มารดา/บิดา/พี่น้อง/บุตร/คู่สมรส/อื่น ๆ)
  • ศาสนา — พุทธ / อิสลาม / คริสต์ / อื่น ๆ
  • การแพ้อาหาร — กรอกรายละเอียด หรือ "ไม่มี"

4.2 ผู้เข้าร่วมเพิ่มเติม

  • เลือกจำนวนผู้เข้าร่วม (รวมผู้จอง) จาก dropdown
  • กรอกข้อมูลของแต่ละคน: ชื่อ, เลขประจำตัว, ศาสนา, แพ้อาหาร, ความสัมพันธ์, อายุ
  • หากเลือกความสัมพันธ์เป็น "บุตร / ธิดา" ต้องกรอกอายุ

4.3 ค้นหาผู้ต้องขัง

ดูตัวอย่างช่องค้นหาและ dropdown ได้จากม็อกอัพด้านบน (ส่วนค้นหาผู้ต้องขัง)

  1. พิมพ์เลขผู้ต้องขัง หรือชื่อ-นามสกุล ในช่องค้นหา
  2. ระบบจะแสดงรายการที่ตรงกัน (สูงสุด 8 รายการ)
  3. คลิกเลือกผู้ต้องขังจาก dropdown
  4. ข้อมูลจะแสดงในกรอบสีเขียวยืนยัน — ชื่อถูกปิดบัง (mask) เพื่อความเป็นส่วนตัว
  5. คลิกพื้นที่ว่างเพื่อปิด dropdown

หากระบบไม่พบผู้ต้องขังที่ต้องการ แสดงว่าข้อมูลในฐานข้อมูลยังไม่มี — สามารถป้อนข้อมูลผ่านหน้า "จัดการผู้ต้องขัง" ก่อน

⚠️ ความเป็นส่วนตัว: ชื่อผู้ต้องขังจะถูกปิดบัง (แสดงเฉพาะชื่อต้น + 4 ตัวแรกของนามสกุล) เพื่อป้องกันข้อมูลส่วนบุคคล

4.4 เลือกวันที่

  • เลือกวันที่ต้องการเข้าร่วมกิจกรรมจาก input date
  • ค่าบริการรวมจะคำนวณอัตโนมัติ

4.5 บันทึก

  • กดปุ่ม 💾 บันทึกการจอง
  • ระบบจะบันทึกไปยัง Google Sheet ทันที
  • สถานะเริ่มต้น: รอตรวจสอบวินัย
  • เลขอ้างอิง (Ref) จะถูกสร้างอัตโนมัติ

13. เคล็ดลับการใช้งาน

การรีเฟรชข้อมูล

  • ข้อมูลจะอัปเดตอัตโนมัติทุก 30 วินาที
  • หรือกดปุ่มรีเฟรช (🔄) ที่มุมบนขวา
  • บนมือถือสามารถใช้ Pull-to-Refresh (ดึงลง) เพื่อรีเฟรช

การแจ้งเตือน

  • 🔔 กระดิ่งแจ้งเตือนจะแสดงเมื่อมีรายการจองใหม่ในสถานะ "รอตรวจสอบ"
  • คลิกที่กระดิ่งเพื่อดูรายละเอียด
  • คลิกที่รายการในแผงแจ้งเตือนเพื่อไปที่รายการนั้น

ปุ่มคู่มือ

  • คลิก 📖 คู่มือ ที่มุมบนขวาของหน้า Admin เพื่อเปิดคู่มือนี้ในแท็บใหม่
  • ใช้ปุ่ม 🖨️ พิมพ์ ที่มุมบนขวาของคู่มือเพื่อพิมพ์

การจัดการหน้าจอบนมือถือ

  • ระบบปรับขนาดอัตโนมัติตามหน้าจอ (Responsive)
  • บนมือถือเมนูด้านข้างจะถูกซ่อนและแสดงปุ่ม ☰ เพื่อเปิด
  • แถบนำทางด้านล่าง (Bottom Nav) แสดงบนมือถือเพื่อการเข้าถึงที่รวดเร็ว

14. การแก้ไขปัญหาเบื้องต้น

ปัญหาสาเหตุวิธีแก้
🔴 เข้าสู่ระบบไม่ได้ ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง ตรวจสอบข้อมูลประจำตัวและลองใหม่ — ติดต่อ Superadmin ถ้าลืมรหัสผ่าน
🟡 โหลดข้อมูลไม่สำเร็จ ไม่สามารถเชื่อมต่อ Google Sheet หรืออินเทอร์เน็ต ตรวจสอบการเชื่อมต่ออินเทอร์เน็ต รอสักครู่แล้วกดรีเฟรช
🟡 ข้อมูลไม่แสดง ตัวกรอง (Filter) อาจซ่อนข้อมูล ล้างตัวกรองทั้งหมด: สถานะ = "ทุกสถานะ", วันที่ = "ทุกวัน", แดน = "ทุกแดน"
🔴 บันทึกข้อมูลไม่สำเร็จ ลิงก์ Google Apps Script ขาด หรือมีปัญหาเซิร์ฟเวอร์ ตรวจสอบ URL Apps Script ในหน้าตั้งค่า ติดต่อผู้ดูแลระบบ
🟡 ค้นหาผู้ต้องขังไม่เจอ ข้อมูลผู้ต้องขังยังไม่ได้นำเข้า หรือยังไม่โหลด ไปที่หน้า "ผู้ต้องขัง" → นำเข้า CSV → กด Sync Wings
🟡 Modal ไม่แสดง หรือแสดงผิดปกติ อาจมี CSS ขัดกัน หรือ Cache เดิม กด Ctrl+F5 (Hard Refresh) เพื่อล้าง Cache
🚨 หากปัญหายังไม่หาย: กรุณาติดต่อผู้ดูแลระบบ (Superadmin) หรือแจ้งที่ทีมพัฒนาผ่านช่องทางที่กำหนด
