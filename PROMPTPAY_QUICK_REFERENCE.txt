## 🎯 ผลลัพธ์

**ก่อน:** QR Code ไม่สแกนได้  
**หลัง:** QR Code สแกนได้กับ Mobile Banking ทั้งหมดของไทย

### ธนาคารที่รองรับ
- ✅ ธนาคารกรุงไทย (KTB)
- ✅ ธนาคารกสิกรไทย (KBANK)
- ✅ ธนาคารไทยพาณิชย์ (SCB)
- ✅ ธนาคารทิสโก้ (TTB)
- ✅ Promptpay App
- ✅ เว็บแบงกิง

## 🚀 ทดสอบ

1. เปิด status.html
2. ค้นหาการจองที่สถานะ "รอชำระเงิน"
3. กด "ดำเนินการชำระเงิน"
4. เห็น QR Code → **สแกนด้วย Mobile Banking**
5. ควรแสดงจำนวนเงิน + ชื่อบัญชี ✓

**ถ้ายังไม่สแกนได้:** ใช้บัญชีธนาคาร (fallback)
```
บัญชี: 137-1-09488-8 (กรุงไทย)
ชื่อ: ทัณฑสถานบำบัดพิเศษกลาง
```
