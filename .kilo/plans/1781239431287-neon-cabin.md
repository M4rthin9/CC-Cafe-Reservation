# แผนการแก้ไขราคาตรวจผู้เข้าร่วม - เด็กอายุต่ำกว่า 5 ขวบ/5-8 ขวบ

## ปัญหา
เมื่อกดอนุมัติผู้เข้าร่วมใน admin panel ราคาเด็กที่อายุ < 5 ขวบ หรือ 5-8 ขวบ คำนวณผิด
- เด็ก < 5 ขวบ ควรเป็น 0 บาท (ฟรี)
- เด็ก 5-8 ขวบ ควรเป็น 500 บาท
- แต่ตอนนี้กดอนุมัติแล้วเป็น +1000 หรือ -1000 ทุกครั้ง

## สาเหตุ
ใน `src/js/admin.js` มีการคำนวณราคาแบบง่ายๆ โดยไม่คำนึงถึงอายุเด็ก:
- บรรทัด 1435: `row.total = (approvedRel + 1) * 1000;`
- บรรทัด 1813: `row.total = (approvedRel + 1) * 1000;`

## วิธีแก้
ใช้ logic เดียวกับที่ `booking.js` ใช้ในฟังก์ชัน `calculateTotal()` (บรรทัด 198-227)

### แก้ไข 2 จุดใน admin.js:

#### 1. ฟังก์ชัน `updateVisitorApproval` (บรรทัด ~1430)
เพิ่มการคำนวณราคาโดยคำนึงถึงอายุเด็ก โดยใช้ข้อมูล `extraVisitorNames` ที่เก็บอายุไว้ในฟอร์แมต `|name|id|relation|age|

#### 2. ฟังก์ชัน `approveAllVisitorsInDetail` (บรรทัด ~1811)  
เพิ่มการคำนวณราคาโดยคำนึงถึงอายุเด็ก

### รายละเอียดการคำนวณ
```javascript
let total = 1000; // ผู้จองหลัก
extras.forEach(v => {
  let fee = 1000; // ค่าเริ่มต้นผู้ใหญ่
  if (v.relation === 'บุตร / ธิดา') {
    const a = parseInt(v.age, 10);
    if (!isNaN(a)) {
      if (a < 5) fee = 0;       // เด็ก < 5 ฟรี
      else if (a <= 8) fee = 500; // เด็ก 5-8 ใช้ 500
    }
  }
  total += fee;
});
```

1. แก้ฟังก์ชัน `updateVisitorApproval` เพื่อคำนวณราคาที่ถูกต้อง

3. ตรวจสอบให้แน่ใจว่าใช้ logic เดียวกับ `booking.js`
