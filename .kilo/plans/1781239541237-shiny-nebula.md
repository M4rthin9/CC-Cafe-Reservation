# AI Chat Bot Integration - NEXUS AI Command

## Requirements
- Add AI chat bot to admin.html, index.html, booking.html, and status.html
- Free AI solution (no paid API)
- Answers user questions about the reservation system

## Solution Options

### Option 1: Knowledge-Base Chatbot (Recommended - No API needed)
- Pre-defined Q&A responses stored in JavaScript
- Answers common questions about pricing, booking steps, policies
- No external API calls, fully client-side
- No cost, instant response

### Option 2: Hugging Face Free Tier API
- Uses free tier of Hugging Face Inference API
- Requires free account signup
- May have rate limits (30k tokens/month)

## Implementation Plan (Knowledge-Base Approach)

### Files to Modify
| File | Changes |

| `admin.html` | Add chat button + modal |
| `index.html` | Add chat button + modal |
| `booking.html` | Add chat button + modal |

### Features
- Floating chat button (bottom-right corner)
- Chat modal with message history
- Quick buttons for common questions
- Knowledge base for:
  - Pricing information (child discounts, adult price)
  - Booking steps (4-step process)
  - Reservation policies
  - How to check status
  - What to bring on visit day

### UI Design
- Match existing site colors (dark blue theme)
- Thai language interface
- Responsive for mobile

## Step-by-Step Implementation
1. Create `src/js/chatbot.js` with knowledge base
2. Add chat HTML elements to each page
3. Add chat CSS styles
4. Add quick question buttons
