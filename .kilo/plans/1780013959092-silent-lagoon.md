# Plan: Improve Reservations Table UX/UI for PC and Mobile

## Problem Analysis

Looking at the current implementation:
1. **PC View Issues**: 
   - The table has 10 columns which can cause horizontal overflow on smaller PC screens
   - Some columns are hidden with `hide-mobile` class even on PC

2. **Mobile View Issues**:
   - Current card layout CSS is in place but may not be properly styled
   - Column labels exist via `data-label` attributes but need cleaner presentation

## Proposed Solution

### 1. PC View Improvements
- Keep essential columns visible with proper spacing
- Columns order: เลขอ้างอิง | วันที่จอง | วันที่ร่วมกิจกรรม | ผู้เข้าร่วม | สถานะ | จัดการ
- Remove `hide-mobile` class for date/wing columns on PC - they should only hide on mobile
- Add better column width distribution

### 2. Mobile View Improvements  
- Refine card layout with proper padding and spacing
- Make "จัดการ" buttons full-width and stack properly
- Ensure data is clearly readable with appropriate label styling

### 3. Files to Modify
- `src/css/admin.css` - Refine responsive table styles
- `src/js/admin.js` - Adjust column visibility logic

## Implementation Steps
1. Fix CSS column widths for PC view with proper `table-layout: fixed`
2. Remove `hide-mobile` from non-essential columns in HTML
3. Improve mobile card styling with better spacing
4. Ensure action buttons are properly sized on mobile
