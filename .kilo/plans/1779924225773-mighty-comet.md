# User Management and Event Logging Plan (Backend & Admin Dashboard)

## 1. RBAC System Implementation
### A. Permission Matrix
| Role              | Permissions                                | API Endpoints Accessible | Dashboard Access     |
|-------------------|--------------------------------------------|--------------------------|----------------------|
| **Superadmin**    | All actions                                | **All**                  | Full permissions     |
| **Finance**       | Payment verification, slip checking        | /cancelBooking/<ref><br>/updateStatus/<ref><br>/uploadSlip | Limited permissions  |
| **Discipline Officer** | Status approval (pre-payment)          | /updateStatus/<ref> (pre-payment only) | Limited permissions  |
| **Disciplinary Department** | Visitor request approval/rejection    | /updateVisitorApproval/<ref> | Limited permissions  |

### B. Event Log Schema Design
```json
{  timestamp: "YYYY-MM-DD HH:mm:ss",
  username: string,
  action: action name (e.g., login, money_cancel),
  targetRef: string,
  details: { key-value pairs relevant to action },
  result: "success"|"denied"|"error",
  metadata: { ip, userAgent (optional) }
}
```
