# Plan: Enhanced Dashboard Table UX/UI Improvements

## Requirements Analysis

1. **Dashboard table should be full-width without horizontal scrolling** - Make the table extend full page width
2. **Better data visibility** - All columns should be visible without needing to scroll horizontally
3. **Improved eventlog view** - Should already have scrollable container with max-height 500px
4. **Overall UI enhancement** - Make the interface more beautiful and user-friendly

## Current Issues

- The table has `overflow-x:auto` wrapper causing horizontal scroll on small screens
- Some columns are hidden on mobile (`hide-mobile` class)
- The eventlog container is in place but could use better styling

## Implementation Plan

### 1. Table Full-Width Layout (admin.css)
- Remove horizontal scroll wrapper or make it work better
- Use responsive column widths with `table-layout: fixed`
- Prioritize essential columns (visitor name, prisoner name, status) for smaller screens

### 2. Responsive Table Design (admin.html)
- Remove `overflow-x:auto` wrapper from reservations view
- Let `.table-wrap` handle overflow naturally
- Add horizontal scroll only when absolutely necessary (`max-width: 100%`)

### 3. Enhanced Eventlog Styling (admin.css)
- Better header styling with background colors
- Zebra striping for rows
- Hover effects for better readability
- Sticky header for the eventlog table

### 4. Dashboard Table Improvements
- Show all important columns at once
- Adjust column priorities for mobile view
- Better spacing and typography

## Files to Modify

- `admin.html` - Table wrapper and structure
- `src/css/admin.css` - Table styles and responsive behavior
- `src/js/admin.js` - May need minor adjustments to table rendering

## Implementation Notes

- Use `table-layout: auto` or `table-layout: fixed` depending on content needs
- Allow table to naturally wrap within container
- Consider reducing font size slightly for more data density
- Add sticky positioning for table headers where helpful
