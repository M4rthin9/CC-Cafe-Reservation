# แผนปรับปรุงรายงานรายเดือน - แบบรายงานข้อความ

## ภารกิจ
แปลงรายงานรายเดือนจากกราฟเป็นรายงานข้อความที่เป็นระเบียบ เหมาะสำหรับเสนอผอ.ใหญ่

## รายการทำ

### 1. แก้ไข HTML (admin.html)
- [ ] เอา canvas กราถออกจาก monthlyReportContent
- [ ] เพิ่ม container สำหรับรายงานข้อความ (ตาราง/สรุป)

### 2. แก้ไข JavaScript (src/js/admin.js)
- [ ] แก้ไข `generateMonthlyReport()` ให้คำนวณข้อมูลอย่างละเอียด:
  - จำนวนผู้ต้องขังที่ถูกเบิกไป (unique prisoners)
  - จำนวนญาติ/ผู้เยี่ยมทั้งหมด (total visitors)
  - ยอดเงินชำระแล้ว/ยังไม่ชำระ (revenue breakdown)
  - จำนวนการจอง (booking count)
  
- [ ] แก้ไขฟังก์ชันแสดงผล:
  - ลบ `drawMonthlyFinanceChart()` (ไม่ใช้)
  - ลบ `drawMonthlyVisitorChart()` (ไม่ใช้)
  - เพิ่ม `renderMonthlyTextReport()` - แสดงข้อมูลเป็นตัวหนังสือ

### 3. รูปแบบรายงานที่แนะนำ
```
📊 รายงานรายเดือน ประจำเดือน xxxx-xx
จากวันที่: xx/xx/xxxx ถึงวันที่: xx/xx/xxxx

สรุปยอดเงิน:
• ยอดจองทั้งหมด: xxx บาท
• ชำระแล้ว: xxx บาท
• ยังไม่ชำระ: xxx บาท
• จำนวนการจอง: xx รายการ

สรุปผู้ต้องขัง:
• จำนวนผู้ต้องขังที่เข้าร่วม: xx คน
• แดนที่อยู่: แดน 1, แดน 2, ... (รายการ)

สรุปญาตี้:
• ผู้ใหญ่: xx คน
• เด็ก 5-8 ปี: xx คน
• เด็กต่ำกว่า 5 ปี: xx คน
• รวมญาตี้: xx คน
```
