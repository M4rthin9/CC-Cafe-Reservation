# Plan: Restore Role-Based Permissions

## Problem Analysis

Role-based permission checks were removed from admin.js action handlers (comments show "Removed permission check - everyone can..."). Need to restore proper permission enforcement:

- **Superadmin/Admin**: All permissions (full access)
- **Vinai**: Can only see/process "รอตรวจสอบวินัย" status (discipline check) - approve AND reject
- **Tadtel**: Can only see/process "รอตรวจสอบผู้เข้าร่วม" status (participant approval) + visitor_approval
- **Finance**: Can only see/process "รอชำระเงิน", "ชำระแล้ว", "เสร็จสิ้น" status (payment related)

## Permissions Matrix (PERMISSIONS config)

Current PERMISSIONS config (lines 2-9) already correct for button visibility, but missing `reject_discipline` for Vinai.

## Implementation Plan

### 1. Add missing permission to PERMISSIONS config

Add `reject_discipline` permission for Vinai role:
```javascript
Vinai: ['approve_discipline', 'reject_discipline', 'view_slip', 'view_detail']
```

### 2. Add permission checks to action handlers

In each function, add check at start:
```javascript
if (!hasPermission('action_name')) {
  alert('คุณไม่มีสิทธิ์ทำรายการนี้');
  return;
}
```

**Functions requiring permission checks:**

| Function | Permission | Role |
|----------|-----------|------|
| updateStatus (discipline stage) | approve_discipline | Vinai |
| updateStatus (participant stage) | approve_participant | Tadtel |
| updateStatus (payment revert) | reject_payment | Finance |
| confirmPayment | confirm_payment | Finance, Superadmin, Admin |
| cancelBooking | cancel | Finance, Superadmin, Admin |
| updateVisitorApproval | visitor_approval | Tadtel |
| approveParticipantInDetail | approve_participant | Tadtel |
| rejectParticipantInDetail | approve_participant | Tadtel |

### 3. Update button visibility in renderTable() (lines 322-331)

Replace status-only checks with permission-based checks:

- Discipline buttons (lines 322-323): Check `hasPermission('approve_discipline')`
- Participant buttons (lines 324-325): Check `hasPermission('approve_participant')`
- Payment buttons (lines 326-327): Check `confirm_payment` or `reject_payment`
- Cancel button (line 328): Check `hasPermission('cancel')`

## Files to Modify

- `src/js/admin.js`: Update PERMISSIONS config + add permission checks to action handlers + update button visibility logic in `renderTable()`
