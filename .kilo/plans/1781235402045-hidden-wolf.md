# แผนเพิ่ม NEXUS AI Command Chat Assistant

## ภารกิจ
เพิ่ม AI ช่วยเหลือในหน้า admin และ index เพื่อให้บริการผู้ใช้

## ลักษณะการทำงาน
- แชทบ็อทแบบจำลองที่ตอบคำถามเกี่ยวกับระบบ
- ปุ่มเปิด/ปิดแชทที่มุมหน้าต่าง
- สไตล์คล้าย LINE OA หรือ Facebook Chat

## ไฟล์ที่ต้องแก้ไข

### 1. admin.html
- เพิ่มปุ่ม AI chat ที่มุมขวาล่าง
- เพิ่ม chat widget container
- เพิ่ม JavaScript สำหรับ chat functionality

### 2. index.html (จำนวนผู้เยี่ยม)
- เพิ่มปุ่ม AI chat ที่มุมขวาล่าง
- เพิ่ม chat widget container

### 3. ไฟล์ CSS ใหม่หรือเพิ่มเติม
- สไตล์สำหรับ chat widget
- ปุ่ม toggle
- หน้าตาข้อความแชท

## รายการทำ

### ขั้นตอนที่ 1: สร้าง chat widget HTML
- [ ] เพิ่ม HTML structure สำหรับ chat widget ที่ทั้งสองไฟล์
- [ ] ตำแหน่งมุมขวาล่างของหน้าจอ

### ขั้นตอนที่ 2: เพิ่ม CSS styling
- [ ] สไตล์สำหรับ floating chat button
- [ ] สไตล์สำหรับ chat window
- [ ] สไตล์สำหรับข้อความ user และ bot

### ขั้นตอนที่ 3: เพิ่ม JavaScript logic
- [ ] ฟังก์ชันเปิด/ปิด chat
- [ ] รายการคำถาม/คำตอบสำเร็จรูป (FAQ style)
- [ ] การจัดการข้อความแสดงผล

### ขั้นตอนที่ 4: ทำคำสั่ง AI สำคัญ
- คำถามเกี่ยวกับการจอง
- คำถามเกี่ยวกับสถานะ
- คำถามเกี่ยวกับค่าใช้จ่าย
- คำถามเกี่ยวกับแดน/ผู้ต้องขัง

## สไตล์ที่แนะนำ
- ใช้สีธีมหลักของระบบ (#0B2545, #2E5238)
- ไอคอน AI สีฟ้า/เขียว
- แสดงผลแบบ card/dialog สไตล์มือถือ
