# Fix Plan: Status Changes Not Persisting in Database

## Problem Analysis

Two critical bugs prevent admin actions (approve/reject/cancel) from persisting to the Google Sheet:

### Bug 1: Missing Authorization Check in Google Apps Script (google_apps_script_updated.js)
- **Location**: `doPost` function, lines 396-435
- **Issue**: The authorization logic only guards `getAll` action explicitly
- **Code flow**:
  - Public actions (`uploadSlip`, `updateSlipAndStatus`) are allowed without auth
  - `getAll` is explicitly checked for authorization
  - All other actions (`updateStatus`, `cancelBooking`, `updateVisitorApproval`, etc.) **fall through without any auth check**
  - Result: These actions execute but fail silently because `username` is undefined

### Bug 2: Missing Username in Client-side POST Requests (src/js/admin.js)
- **Location**: Multiple functions
- **Issue**: POST requests to update status do not send `username`
- **Affected functions**:
  - `updateStatus` (line 1020): sends only `pass`, missing `username`
  - `confirmPayment` (line 1057): sends only `pass`, missing `username`
  - `rejectPayment` (line 1089): sends only `pass`, missing `username`
  - `cancelBooking` (line 1121): sends only `pass`, missing `username`
  - `updateVisitorApproval` (line 1166): sends only `pass`, missing `username`

## Root Cause in isAuthorized Function

```javascript
function isAuthorized(username, pass) {
  // Legacy password-only auth for backward compatibility
  if (String(pass) === String(LEGACY_STAFF_PASS)) return true;
  
  // RBAC auth - requires valid username
  const user = getUserByUsername(username);
  if (!user) return false;
  
  return String(user.password) === String(pass);
}
```

When `username` is undefined:
1. `pass === LEGACY_STAFF_PASS` fails (pass is user-specific)
2. `getUserByUsername(undefined)` returns null
3. Authorization fails → action blocked

## Implementation Plan

### Fix 1: google_apps_script_updated.js

**Change lines 396-435 from:**
```javascript
// ===== Public actions (no login required) =====
const publicActions = ['uploadSlip', 'updateSlipAndStatus'];
if (publicActions.includes(action) && (username === 'public' || !username)) {
  // allow public slip upload / payment confirmation
} else if (action === 'getAll' && !isAuthorized(username, pass)) {
  return jsonResp({ status: 'error', message: 'Unauthorized' });
}

// ── get all reservations (POST) ──
if (action === 'getAll') {
  ...
} else if (!isAuthorized(username, pass)) {
  logEvent(username || 'unknown', action, body.ref || '', { reason: 'unauthorized' }, 'denied');
  return jsonResp({ status: 'error', message: 'Unauthorized' });
}
```

**To:**
```javascript
// ===== Public actions (no login required) =====
const publicActions = ['uploadSlip', 'updateSlipAndStatus'];
if (publicActions.includes(action) && (username === 'public' || !username)) {
  // allow public slip upload / payment confirmation
} else if (!publicActions.includes(action) && !isAuthorized(username, pass)) {
  logEvent(username || 'unknown', action, body.ref || '', { reason: 'unauthorized' }, 'denied');
  return jsonResp({ status: 'error', message: 'Unauthorized' });
}

// ── get all reservations (POST) ──
if (action === 'getAll') {
  ...
}
```

This ensures ALL non-public actions are properly authorized.
